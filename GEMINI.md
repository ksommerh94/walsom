# Walsom Project Instructions

## SEO Standards
- All pages must have a unique `<title>` and `<meta name="description">`.
- Primary heading must use an `<h1>` tag (can be styled to match design).
- All images (`<img>`) must have descriptive `alt` tags in Spanish.
- External links should include `rel="noopener noreferrer"`.

## Performance Standards
- Avoid using large GIFs for backgrounds. Prefer MP4 video with `autoplay muted loop playsinline`.
- Background videos should be compressed to under 5MB if possible.
- Project images should be optimized to under 500KB.

## Infrastructure
- All traffic must be forced to HTTPS and WWW via `.htaccess`.
- `robots.txt` must point to the `sitemap.xml`.
